# Ride Free

A horse care game set around a stable. As the owner, you are responsible for your horse: it needs to eat, drink, be moved, ridden, played with and loved, just like a real animal.

## How to play

Open `index.html` in any modern web browser. There is nothing to install or build. Your progress is saved in the browser automatically.

## Languages

The game is available in English and German. Use the EN / DE switch at the top of the screen to change language.

## Files

- `index.html` is the current version of the game.
- `v1-2d.html` is the earlier 2D prototype, kept for reference.

## Play on iPhone or iPad

Open https://lebot09.github.io/RideFree/ in Safari, tap the Share button, then "Add to Home Screen". Ride Free then opens full screen from its own icon, and it keeps working offline once it has loaded once.
